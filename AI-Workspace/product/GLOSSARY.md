## Domain terms (Italian e-invoicing / regime forfettario)

- 🟢 **Regime forfettario** — Italian flat-tax scheme for freelancers/sole proprietors; this app is built specifically for it (VAT-exempt invoicing, no INPS rivalsa, no ritenuta d'acconto). Source: `README.md`, `fatturaPaXmlGenerator.js`.
- 🟢 **FatturaPA** — the mandatory Italian electronic invoice XML format (schema v1.2.2 in this codebase). Generated by `fatturaPaXmlGenerator.js`.
- 🟢 **SDI (Sistema di Interscambio)** — Italy's state-run invoice exchange system; routes e-invoices to recipients and returns delivery/outcome receipts. Official address used in this app: `sdi01@pec.fatturapa.it`.
- 🟢 **PEC (Posta Elettronica Certificata)** — Italian certified email; the legally required transport channel for submitting FatturaPA invoices to SDI and receiving its receipts. Implemented via SMTP send (`pecService.js`) and IMAP polling (`sdiRicevuteService.js`).
- 🟢 **RegimeFiscale RF19** — FatturaPA tax-regime code for forfettario, used in generated XML.
- 🟢 **Natura IVA N2.2** — FatturaPA VAT-nature code for forfettario (VAT-exempt), used in generated XML.
- 🟢 **DatiBollo** — virtual stamp duty section in FatturaPA XML, applied above a value threshold.
- 🟢 **SDI receipt types** (recognized by `sdiRicevuteService.js`): RC, NS, MC, NE, EC, DT, AT — codes for delivery/acceptance/rejection/notification outcomes from SDI.

## Codebase terms (Italian naming used throughout the code)

- 🟢 **Fornitore** — supplier (the app owner/consultant issuing invoices). One per install.
- 🟢 **Cliente** — client (an invoice recipient). Stored as `config.clienti[]`, an array — the app supports multiple concurrent clients, each with a stable `id` and own hourly rate; `attivo:false` marks a soft-deleted client (hidden from pickers, still resolvable for historical data).
- 🟢 **Compenso** — fee/compensation, computed from timesheet hours × rate.
- 🟢 **Anteprima** — preview (e.g. `anteprimaFattura` = invoice preview).
- 🟢 **Fattura Pro-Forma** — the pro-forma invoice preview generated before final XML generation/send.
- 🟢 **Timesheet** — monthly hour log per day, the billing basis.
- 🟢 **Riepilogo** — summary (e.g. monthly hours summary computed by `calcolaRiepilogo`).
- 🟢 **Impostazioni** — settings (the wizard view: `ImpostazioniView.vue`).
- 🟢 **Importa storico** — historical import (one-off import of legacy timesheets/invoices).
- 🟢 **Passo / Passi** — wizard step / steps (`passoAttivo`, `wizardImpostazioniPassi.js`).
- 🟢 **Regime forfettario (dashboard)** — the app's yearly income-vs-threshold and estimated-tax view (`forfettarioService.js`, `DashboardView.vue`), distinct from the regulatory term above.
- 🟢 **Promemoria** — reminder (end-of-month timesheet-fill reminder, `reminderService.js`).
